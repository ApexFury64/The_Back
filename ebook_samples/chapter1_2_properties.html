Chapter 1.2: Properties of Rational Numbers

In this section, we will explore the mathematical properties of rational numbers under the four basic arithmetic operations: Addition, Subtraction, Multiplication, and Division.

1. Closure Property

A set is closed under an operation if performing that operation on any elements of the set always produces another element of that same set.

Operation Example Is Closed?
Addition (3/8) + (5/8) = 1 (rational) Yes
Subtraction (2/3) - (5/3) = -1 (rational) Yes
Multiplication (-2/3) * (4/5) = -8/15 (rational) Yes
Division (3/5) / 0 = Undefined No (due to division by zero)

2. Commutativity Property

Addition and multiplication are commutative for rational numbers. Subtraction and division are NOT commutative.

• Addition: a + b = b + a

• Multiplication: a * b = b * a

• Subtraction: a - b ≠ b - a

3. Associativity Property

Addition and multiplication are associative. For any three rational numbers a, b, and c:

a + (b + c) = (a + b) + c
a * (b * c) = (a * b) * c
